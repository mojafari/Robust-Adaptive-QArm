# Learning-Based Adaptive Robust Control of a 4-DOF Robot Manipulator

This repository contains code and supporting resources related to the research project:

**Learning-Based Adaptive Robust Control of a 4-DOF Robot Manipulator**

## Overview

The objective of this work is to develop and validate a learning-based adaptive robust control framework for a 4-DOF robot manipulator. The research investigates the integration of learning-based adaptation with robust control techniques to improve trajectory tracking, disturbance rejection, and control performance under modeling uncertainties and varying operating conditions.

The repository may include selected control algorithms, simulation models, implementation codes, and supporting resources associated with the reported results. Additional experimental data, complete code, and supporting materials may be released after publication.
